# P4: LunarLander hybrid + classical baselines

**Task:** LunarLander-v3 with a hybrid model: a classical encoder (8→4) feeding a 4-qubit VQC. Add the **encoder-only ablation**, which replaces the VQC with a linear layer.
**Shared component:** classical MLP baselines and the env wrappers in `qrl/envs.py`, including Box2D.
**Report / video:** Related work, limitations and conclusion.

## Your model (plan defaults)
- Linear or small-MLP encoder 8→4, then the 4-qubit VQC (arctan or tanh·π encoding, 4 layers), then 4 actions × output weights. Threshold 200.
- Fallback if the hybrid fails: 8 qubits, one per feature (noisy evaluation only, about 1–1.5 h per noise level).
- **No noise-aware training** (too expensive). Noise enters through evaluation only (Exp B).
- Expect to stay below 200. A clear learning curve and honest analysis beat a missing result.
- Go/no-go on **Sun 1 Nov**: if it isn't learning, keep the best checkpoint plus its curve and move on.

## Shared code you own
MLP baselines for **all four tasks**, plugged into P1's `q_values` / `train` interface (`cfg.model`):
- `mlp_small`: parameter-matched to that task's VQC (about the same count; use `count_params`)
- `mlp_large`: 2×64 ReLU (`cfg.mlp_large_hidden`)
- `encoder_only` (LunarLander): the same encoder with the VQC replaced by a linear layer
- FrozenLake MLPs take the 16-way one-hot from `qrl.envs.one_hot_obs`, not the state index.

Running the MLPs on all four envs early also checks that P1's training loop works.
