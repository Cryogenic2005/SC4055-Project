## Noise conventions to write in the report
- `depolarizing=p` = PennyLane `DepolarizingChannel(p)` after every gate, per wire, so ⟨Z⟩ → (1 − 4p/3)⟨Z⟩. Device gate error ε converts as p = 1.5ε (1 qubit), via `gate_error_to_depol_p`.
- Readout = `BitFlip(p)` before measurement, so ⟨Z⟩ → (1 − 2p)⟨Z⟩. PennyLane 0.45.1's `readout_prob` is broken; a test guards this.
- Presets use exact expectations; shot noise is its own axis.
- Shots are never combined with backprop.
