# P3: Acrobot + evaluation harness and plots

**Task:** Acrobot-v1 with 6 qubits. It tests how the cost of noise and the noise tolerance scale with circuit size.
**Shared component:** `qrl/evaluate.py` (stub, you write it) and `analysis/` (aggregation and plotting).
**Report / video:** Results figures; **video editor**.

## Your circuit (plan defaults)
- 6 qubits (one per observation feature), arctan encoding with re-uploading, 2–5 layers, about 90–180 parameters.
- 3 actions from ⟨Z₀⟩, ⟨Z₁⟩, ⟨Z₂⟩ × trainable output weights. Threshold −100.
- Noisy training is expensive at 6 qubits (about 257 ms per noisy batch gradient, about 50 min per 100k steps). Run Exp C for **one condition (depolarizing=0.01), 3 seeds** only.

## Shared code you own
`qrl/evaluate.py`, generalised from `tasks/frozenlake/evaluate.py` (working):
```python
evaluate_checkpoint(cfg, checkpoint, conditions=NOISE_MENU, n_episodes=100)
# appends to runs/eval/<task>_<model>_<seed>.csv with EvalLogger; always includes eval_noise_type=none
```
`analysis/analyze.py` follows `docs/analysis_spec.md`:
- normalized score = (R − R_random)/(R_threshold − R_random)
- headline figure: normalized score vs noise strength, one line per task, one panel per noise type
- noise tolerance (largest level keeping 90% of the noise-free score) vs qubit count
- C-vs-B comparison with bootstrap CIs

The analysis thread has a draft of analyze.py and dummy-data generator; pull it in from there.
