# P1: CartPole + core QAgent / DQN loop

**Task:** CartPole-v1, the reference task. Reproduce Skolik et al.'s noise thresholds (solved at depolarizing p ≤ 0.01, fails at p = 0.1).
**Shared component:** `qrl/agent.py` (QAgent) and `qrl/dqn.py` (DQN loop, optax setup). Both are currently interface stubs, and you write them.
**Report / video:** Method section; video intro.

## Your circuit (plan defaults)
- 4 qubits, 5 layers, about 62–94 parameters.
- Encoding: `arctan(x)` of each of the 4 observations, RX, **data re-uploading** before every layer, **trainable input scaling** λ.
- Layer: RX, RY, RZ on every qubit, then a CZ ring.
- Readout: 2 actions from ⟨Z₀Z₁⟩ / ⟨Z₂Z₃⟩ (Skolik) or ⟨Z₀⟩/⟨Z₁⟩, multiplied by trainable output weights.
- Learning rates (TFQ recipe): input 0.001, circuit 0.001, output 0.1, via `optax.multi_transform`.
- Threshold 475 (Gymnasium registered value; say "475, docs say 500" in the report).

## Shared code you own
Generalise `tasks/frozenlake/agent.py` and `tasks/frozenlake/train.py` (both working, reviewed by P2) into:
```python
params = init_params(cfg, key)               # qrl/agent.py
q      = q_values(params, x, spec, key)      # (batch, d) -> (batch, n_actions)
train(cfg) -> dict                           # qrl/dqn.py; writes runs/train/<run_name>.csv
```
Requirements: `jax.jit` + `jax.vmap` fast path by default; parameter-shift when `cfg.noise` is `shots=N`; checkpoint every 25 episodes with a short greedy eval, keeping `best.pkl` (the FrozenLake trainer shows how); and an MLP mode so P4's baselines reuse the same loop.

Lessons from FrozenLake that apply to you:
- Q = w·⟨Z⟩ (signed) worked; Q = w·(⟨Z⟩+1)/2 couldn't fit negative targets.
- Late collapse happens (train mean 1.0, greedy 0.0), so always keep `best.pkl`.
